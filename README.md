#Introduction

This is just a basic web app that sends requests to Google's gemini-3 flash model to generate code and help users with the process of identifying bugs.
It gives you a code snippet with a single bug and its up to the user to find and describe the bug and see if they correctly identifies the bug or not.
I made this to help people(Including me) in there journey of Informatics olympiads so that they can practise identifying flaws in their logic and more.

Hope you enjoy.
